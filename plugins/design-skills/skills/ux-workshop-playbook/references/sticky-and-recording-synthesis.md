# Sticky And Recording Synthesis

Use this after a workshop when the user provides sticky notes, board exports, screenshots, recordings, transcripts, notes, or mixed evidence.

## Source Handling

Start with an inventory:

- Source type: stickies, transcript, recording summary, chat, notes, board screenshot, export, slides.
- Workshop goal.
- Participants or roles if provided.
- Time period or agenda section.
- Legibility or transcript limits.
- Missing sources that could change synthesis.

If raw audio or video cannot be processed with available tools, ask for a transcript, meeting notes, or recording summary.

## Synthesis Workflow

1. Extract atomic notes. Keep one idea per item.
2. Label each item as observation, participant opinion, decision, action, assumption, risk, question, or quote.
3. Cluster by meaning, not by identical wording.
4. Name themes with plain language.
5. Preserve outliers and disagreements.
6. Convert themes into insights only when there is evidence and implication.
7. Identify decisions, owners, open questions, and recommended follow-up.

## Evidence Labels

- Observed: seen in user behavior, workflow evidence, board activity, or shared artifact.
- Reported: said by a participant or stakeholder.
- Decided: resolved during the workshop.
- Inferred: interpreted from patterns across inputs.
- Assumed: plausible but not supported by current evidence.
- Open: unresolved question or dependency.

## Recording Review

When reviewing a transcript or recording-derived notes, extract:

- Goals stated.
- Decisions made.
- Decision owner.
- Repeated concerns.
- Disagreements or tradeoffs.
- User/customer references.
- Management constraints.
- Risks and dependencies.
- Action items.
- Strong quotes with speaker role if known.

Do not invent quotes. If using paraphrases, label them as paraphrases.

## Output Quality

- Keep raw themes traceable to source evidence.
- Avoid averaging away important disagreement.
- Separate workshop consensus from actual user evidence.
- Call out confidence level and gaps.
- End with concrete next actions.
