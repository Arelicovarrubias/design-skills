# Insight Report Template

Use this for post-workshop summaries, stakeholder readouts, decision logs, and follow-up plans.

## Report Shape

**Workshop purpose**
State why the workshop happened and what decision or learning goal it supported.

**Sources reviewed**
List stickies, transcripts, recordings, notes, boards, slides, or other inputs. Include limits.

**Top insights**
For each insight:

- Insight:
- Evidence:
- Why it matters:
- Confidence:
- Recommendation:

**Decisions**

- Decision:
- Owner:
- Rationale:
- Tradeoffs:
- Follow-up:

**Open questions**

- Question:
- Why it matters:
- Owner:
- Suggested method to answer:

**Risks and tensions**

- Risk or tension:
- Evidence:
- Impact:
- Mitigation:

**Action plan**

- Action:
- Owner:
- Timing:
- Dependency:
- Output:

## Stakeholder Readout

Use this short format for management or cross-functional partners:

- What we set out to decide or learn:
- What we did:
- What we learned:
- What we decided:
- What remains unresolved:
- Recommended next steps:
- Decisions or support needed:

## Follow-Up Recommendations

Recommend follow-up based on gaps:

- More user evidence if the workshop produced assumptions without user signal.
- Technical review if feasibility concerns dominated.
- Decision meeting if authority remains unclear.
- Prototype or concept test if the team aligned on direction but not user value.
- Service blueprint if backstage complexity emerged.
- Roadmap planning if the workshop created more opportunities than the team can pursue.
