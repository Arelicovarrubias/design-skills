# Synthesis Patterns

Use this when the user has research notes, critique comments, workshop outputs, stakeholder feedback, or mixed inputs that need to become decisions.

## Synthesis Workflow

1. Inventory inputs and label their source.
2. Separate facts, observations, interpretations, opinions, and open questions.
3. Group related signals into themes.
4. Name the user or team impact for each theme.
5. Convert themes into insights only when there is evidence and consequence.
6. Translate insights into recommendations, decisions, or follow-up questions.
7. Identify confidence level and evidence gaps.

## Evidence Labels

- Observed: directly seen in user behavior, analytics, support logs, or prototype use.
- Reported: said by participants, stakeholders, customers, or internal teams.
- Inferred: reasoned from patterns but not directly proven.
- Assumed: believed without current evidence.
- Decided: resolved by an accountable owner.
